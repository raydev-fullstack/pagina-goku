## Problemas que encontrei
Os botões da hero estavam sendo cortados.

## Causa
A `.hero-content` tinha uma altura fixa de `400px`, mas o conteúdo precisava de mais espaço.

## Solução
Removi a altura fixa e deixei o navegador calcular automaticamente.
